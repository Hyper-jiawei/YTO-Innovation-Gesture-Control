# 公开验证记录

## 手势模型

当前模型来自1,298张手背照片，接受1,294张，4张未提取到有效手部。类别为1–9、I Love U、ok，左右手共同训练。

时间分段留出：训练775、验证135、测试260、间隔排除124。训练部分每个样本新增4份增强，含原样本共3,875份；验证/测试未扩增。测试257/260正确（98.85%）。置信度阈值0.85时接受251/260（覆盖96.54%），接受部分249/251正确（99.20%）。

这是同一批次、同一操作员范围的分段测试。测试未用于早停，但仍不能表述为独立人员/场景验收结果。原始图片和关键点不公开分发。

## CUDA与YOLO

RTX5060已验证CUDA前向、反向、手势分类和YOLO12推理。MediaPipe关键点当前用CPU。

YOLO12n预热后，对同一1080×810测试图测量12次，推理时长中位数约13.56ms；预热约4.47秒，进入模式后的首个真实结果约109ms。缓存查找时间不等于完整交互时延，以上测试不包含相机采集、MediaPipe和UI。

## 回归测试

公开版本加入YTO图标后，75项完整回归再次通过（2026-10-26）。五个GIF均保留原始动画帧，主页相对图片/文件链接全部存在；上传清单排除采集数据和现场业务日志。测试涵盖框选、条码、证据持久化、时序手势、格口范围、顶部状态、拍照缩略图、后台YOLO与训练数据划分。

模型校验值与原始聚合指标见 [validation_metrics.json](validation_metrics.json)。自动化验证和桌面演示不能替代现场生产验收。
